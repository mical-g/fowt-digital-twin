# Data Directory

This folder contains the datasets generated by Track A (`fowt-digital-twin`) and consumed by Track B for surrogate model training.

## Contents
* `dataset.csv`: The primary parametric simulation dataset generated via Latin Hypercube Sampling (LHS).

## Dataset Specifications & Column Headers
The CSV file includes the following parameters recorded across the operating envelope:
* `u_inf`: Inflow wind speed [m/s]
* `pitch`: Platform pitch angle [deg]
* `tsr` lambda: Tip-speed ratio
* `cp`: Power coefficient
* `ct`: Thrust coefficient
* `cl_span`: Local lift coefficients (C_L) at representative spanwise stations
* `sigma_max`: Maximum Von Mises stress at the blade root [MPa]

## Data Ownership & Workflow
* Track A owns the write permissions for generating and updating files in this folder.
* Track B reads from this folder to train and validate the multi-layer perceptron (MLP) and PINN surrogate models.
